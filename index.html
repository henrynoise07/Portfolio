Rules

  • 90 / 10. Neutrals carry the page; accents appear only on things you can act on or on the active craft.
  • One accent per craft. Cyan is robotics, violet is poem, coral is rap, lime is code — never swap them.
  • Accent as fill needs Ink text. All four accents pass contrast with Ink on top, not with white.
  • The pointer owns hover. Hovered elements take the pointer's current colour, so hover never needs its own shade.
